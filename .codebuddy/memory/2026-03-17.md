## 博客评论功能（含楼中楼、分页、排序）

为博客文章添加了完整评论系统，无需登录，只需昵称即可评论。

### 数据库层
- **`src/lib/schema.ts`** — `comments` 表：id, post_slug, parent_id（楼中楼）, floor（主评论楼数）, nickname, content, created_at
- **`src/lib/db.ts`** — 建表 SQL + `idx_comments_post_slug` + `idx_comments_parent_id` 索引
- **`src/lib/data.ts`** — 评论 CRUD：
  - `getCommentsBySlug(slug, {page, limit, order})` — 分页查主评论 + 批量加载回复
  - `addComment(slug, nickname, content, parentId?)` — 发表评论，主评论自动计算楼数
  - `deleteComment(id)` — 删除评论 + 级联删回复
  - `deleteCommentsBySlug(slug)` — 级联删某文章全部评论
  - `deletePost()` 已改为先级联删评论再删文章

### API 路由
- **`/api/comments`** GET — 按 slug 获取评论，支持 `page` 和 `order` 参数（10条/页）
- **`/api/comments`** POST — 发表评论/回复，支持 `parentId` 参数
- **`/api/admin/comments`** GET — 管理员获取全部评论，支持 `slug` 筛选
- **`/api/admin/comments/[id]`** DELETE — 管理员删评论

### 前端 BlogComments
- 楼数显示（#1, #2...），回复不计入楼数
- 时间排序切换（最早优先 / 最新优先）
- 分页导航（10条/页，上/下一页 + 页码）
- 楼中楼回复：每条主评论有"回复"按钮，展开内嵌回复输入框
- 回复列表缩进展示在主评论下方

### 后台管理
- 博客列表每行增加 💬 查看评论按钮 → 跳转评论 Tab 并自动筛选该文章
- 评论管理支持按文章 slug 筛选 + 清除筛选
- 回复条目左侧缩进 + "回复"标签区分
- 删除评论会级联删除回复

## 数据库迁移修复

- **问题**：已有 `comments` 表缺少 `parent_id` 和 `floor` 列，`CREATE TABLE IF NOT EXISTS` 不会修改已有表结构，导致 `SqliteError: no such column: parent_id`
- **修复**：在 `src/lib/db.ts` 的建表语句之后增加迁移逻辑，逐条执行 `ALTER TABLE comments ADD COLUMN`，用 try-catch 忽略列已存在的错误
- 新库和旧库都能正常工作 ✅

## 站点配置全动态化

### 浏览器标题动态化
- **`src/app/layout.tsx`** — `export const metadata` 改为 `generateMetadata()` 函数，从数据库读取 `site.name` 作为页面标题
  - `default: cfg.name`，`template: '%s | ${cfg.name}'`
  - `description` 也改为动态生成
  - 添加 `export const dynamic = "force-dynamic"` 确保每次请求都重新读取
- **`src/app/admin/layout.tsx`** — 同样改为 `generateMetadata()`，标题变为 `管理后台 | ${cfg.name}`
  - 添加 `export const dynamic = "force-dynamic"` 解决 admin 页面刷新后 Header logo 回退为默认名的问题

### Admin 页面刷新 logo 问题
- **原因**：Next.js 可能缓存了 RootLayout 的服务端渲染结果，导致 SiteConfigProvider 传递的 context 值使用了旧的默认值
- **修复**：根 layout 和 admin layout 都添加 `force-dynamic`，确保每次请求都重新执行服务端代码从数据库读取最新配置

### 关于页自我介绍动态化
- **`src/lib/site-config-dynamic.ts`** — 新增 `about.intro` 字段
- **`src/app/about/page.tsx`** — 硬编码的三段中文介绍改为从 `about.intro` 读取，支持换行分段（`\n` 分隔多段落）
- **`src/app/admin/page.tsx`** ConfigEditor — 新增"关于页面"配置区块，含"自我介绍（换行分段）"多行输入框
- 无数据库 schema 变更（使用现有 `site_config` key-value 表，新增 `about.intro` key 即可）

## 暗色模式 Markdown 正文字体修复

- **问题**：`github-markdown-css` 的暗色模式依赖 `@media (prefers-color-scheme: dark)`，而项目用 `.dark` class 切换主题，导致暗色模式下 `--fgColor-default` 等变量不生效，正文文字为深色看不清
- **修复**：改用 `github-markdown-light.css`（仅亮色基础定义，无 media query），然后在 `globals.css` 中用 `.dark .markdown-body` 选择器手动覆盖全部暗色 CSS 变量（`--fgColor-default: #f0f6fc` 等）
