## 后台图片管理功能

### 后端
- **`src/lib/data.ts`** — 新增：
  - `getAllImages()` — 查询所有图片（不含 base64 data，用于列表）
  - `cleanupUnusedImages()` — 扫描所有帖子 content，用正则收集引用的图片 ID，删除未被引用的孤立图片
- **`src/app/api/admin/images/route.ts`** — 新增 API：
  - GET — 获取图片列表
  - DELETE `?id=xxx` — 删除单张图片
  - POST `?action=cleanup` — 清理未使用图片

### 前端
- **`src/app/admin/page.tsx`** — 新增 `"images"` Tab 和 `ImagesManager` 组件：
  - 缩略图网格（2-4 列自适应），`<img>` 直接引用 `/api/images/{id}` + `loading="lazy"`
  - 悬停显示删除按钮（圆角半透明覆盖）
  - 点击缩略图弹出预览弹窗：全尺寸图片 + 文件信息 + 复制链接 + 删除按钮
  - 工具栏显示总数和总大小
  - "清理未使用"按钮：调用 cleanup API 后显示结果提示
  - 导航新增"图片"项（ImageIcon 图标），位于"留言"和"设置"之间

## lib 目录重组

将 `src/lib/` 下的 9 个文件按功能分组到 4 个子目录：

```
src/lib/
├── db/       ← schema.ts, db.ts, data.ts, types.ts  （数据库层：表定义、连接、数据访问、类型）
├── config/   ← site-config.ts, site-config-dynamic.ts  （站点配置）
```

- `site-config.ts` 和 `blog.ts` 在整个项目中未被引用，但保留在对应目录中
