## 博客 Markdown 渲染重构

问题：旧的 `remark` + `remark-html` 管线不支持表格、公式、代码高亮；后改用 `rehype-highlight` 但存在公式渲染两次、`!=` 被转不等号、代码块无复制按钮、hljs 样式不好看等问题。

最终方案：
- **`src/lib/markdown.ts`** — 新的 unified 管线：
  `remarkParse → remarkGfm → remarkMath → remarkRehype → rehypeKatex → rehypeShiki → rehypeStringify`
  - 不再使用 `rehypeRaw`（会破坏 KaTeX 节点导致公式渲染两次）
  - 不再使用 `rehypeHighlight`（`detect:true` 会误转 `!=` 为不等号）
  - **Shiki**（VS Code 同款引擎）替代 highlight.js，双主题 `github-light` / `github-dark`
  - `rehypeKatex` 必须在 `rehypeShiki` 之前，否则公式节点被破坏

- **`src/components/CopyCodeButton.tsx`** — 客户端组件，自动给 `.prose pre` 添加复制按钮
  - hover 时显示，点击后显示绿色勾 2 秒

- **`src/app/globals.css`** — 移除整个手写 hljs 主题（~100行），改为：
  - Shiki CSS 变量双主题切换：`--shiki-light` / `--shiki-dark`
  - `.dark .prose pre/code/span` 切换到 dark 变量
  - inline code 用 `:not(pre) > code` 选择器避免影响代码块
  - `.copy-btn` 样式：absolute 定位 + hover 显示

- **KaTeX CSS** 通过 CDN 在 `layout.tsx` `<head>` 中引入
- 已清理旧依赖：`remark`, `remark-html`, `rehype-highlight`, `@mdx-js/*`, `reading-time`
