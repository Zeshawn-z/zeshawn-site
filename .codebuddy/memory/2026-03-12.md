# 2026-03-12

## 个人网站页面搭建

基于初始化的 Next.js 16 + Tailwind CSS 4 项目，完成了个人网站的完整页面搭建：

### 创建的文件结构
- `src/components/Header.tsx` — 全局导航栏（响应式，移动端汉堡菜单）
- `src/components/Footer.tsx` — 全局页脚（社交链接）
- `src/lib/types.ts` — 共享类型定义
- `src/lib/projects.ts` — 项目数据源（示例数据）
- `src/lib/experiences.ts` — 经历数据源（示例数据）
- `src/lib/blog.ts` — 博客文章读取工具（解析 .mdx/.md，frontmatter，阅读时间）
- `src/app/layout.tsx` — 全局布局（Header + Footer 包裹）
- `src/app/page.tsx` — 首页（Hero + 精选项目 + 最新博客）
- `src/app/projects/page.tsx` — 项目展示页
- `src/app/about/page.tsx` — 关于页（技术栈 + 时间线经历 + 联系方式）
- `src/app/blog/page.tsx` — 博客列表页
- `src/app/blog/[slug]/page.tsx` — 博客详情页（remark 渲染 markdown）
- `src/app/not-found.tsx` — 404 页面
- `content/blog/hello-world.mdx` — 示例博客文章
- `content/blog/nextjs-guide.mdx` — 示例技术文章
- `src/app/globals.css` — 全局样式（暗色模式、prose 排版）

### 安装的依赖
gray-matter, reading-time, lucide-react, remark, remark-html, date-fns, @next/mdx, @mdx-js/loader, @mdx-js/react

### 技术细节
- 博客使用 `content/blog/` 目录下的 `.mdx` 文件作为内容源
- 使用 gray-matter 解析 frontmatter
- 使用 remark + remark-html 渲染 markdown 内容
- 项目和经历数据在 `src/lib/` 下的 TypeScript 文件中维护
- 所有页面支持暗色模式
- 构建验证通过

## 第五次改造：主题切换改为滑块 + GlowCard 光效裁切修正

### ThemeToggle 重写
- 从单按钮循环切换改为**三段滑块开关**：左浅色(Sun) / 中系统(Monitor) / 右深色(Moon)
- 滑块指示器使用 `translateX` 动画平滑滑动
- 使用 `role="radiogroup"` + `role="radio"` 语义化
- 占位尺寸从 `h-8 w-8` 改为 `h-7 w-[84px]`

### GlowCard 光效修正
- **问题**：之前为了不让外部容器裁切卡片效果而移除了 `overflow-hidden`，导致卡片内部的光效 radial-gradient 溢出卡片边界
- **修复**：恢复 `overflow-hidden` 使光效正确裁切在卡片圆角边界内
- 外部阴影效果改用 `shadow-lg shadow-accent/8`（box-shadow 不受 overflow-hidden 影响）
- 移除了之前的 `-inset-3` 外部光晕层（溢出问题的根源）
- 内部光效改为 `inset-0` 定位 + 合理的 z-index 分层（z-[1] 光效, z-[2] 内容）

## 第六次改造：GlowCard 双层结构 + ScrollReveal 合成层修复

### GlowCard 重构为双层结构
- 外层 wrapper 无 overflow-hidden，包含 `-inset-4` 外层光效可溢出卡片边界
- 内层卡片本体 overflow-hidden + rounded-xl，内层光效被正确裁切
- **移除** 所有旋转(rotateX/Y)和缩放(scale)效果
- **移除** box-shadow 外阴影，由外层光效替代
- 移除各页面 grid 上之前加的 `-m-3 p-3` hack

### ScrollReveal 三态修复
- **根因**：`opacity + transform` 创建 CSS 合成层(compositing layer)，合成层边界=元素尺寸，裁切子元素溢出
- 引入 `hidden → animating → done` 三态，动画结束后完全移除 opacity/transform/transition
- `done` 状态渲染为无样式的普通 div，不再创建合成层

### SpotlightSection
- 内层 z-index 从 `z-10` 降为 `z-[1]`

## 第七次改造：暗黑模式星空效果

### HeroParticles 完全重写
- 浅色模式：保留原有的**连线粒子网络**（蓝色粒子 + 鼠标排斥 + 粒子间/鼠标连线）
- 暗黑模式：**闪烁星空**，完全不同的实现：
  - **星星**：~300 颗，12% 概率为亮星（更大、更亮），每颗有独立闪烁频率和相位
  - **辉光**：亮星有 radialGradient 外发光，hue 在 200-240 之间（蓝紫色调）
  - **十字闪耀**：亮度高于阈值的亮星显示十字光芒
  - **鼠标感应**：鼠标靠近星星时，星星变亮 + 辉光扩大
  - **流星**：随机生成，有渐变拖尾 + 头部辉光，从左上往右下划过
  - **点击涟漪**：点击产生扩散光环，光环扫过时临近星星闪亮
- 切换主题时自动重新初始化对应模式的粒子/星星
