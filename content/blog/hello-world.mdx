## 为什么要搭建个人网站？

作为一名开发者，我一直觉得拥有一个属于自己的网站是很重要的事情。它不仅仅是一个展示作品的地方，更是一个记录成长和分享思考的空间。

### 技术选型

这个网站使用了以下技术栈：

- **Next.js** — React 全栈框架，提供了优秀的开发体验和性能
- **TypeScript** — 类型安全，让代码更可靠
- **Tailwind CSS** — 实用优先的 CSS 框架，快速构建美观的界面
- **MDX** — 在 Markdown 中使用 React 组件

### 内容规划

我计划在这里分享以下内容：

1. **技术博客** — 深入探讨前端技术、架构设计和最佳实践
2. **项目记录** — 记录项目开发过程中的思考和经验
3. **学习笔记** — 整理学习新技术时的心得体会

### 写作的意义

> 写作是思考的最佳方式之一。当你试图把一个概念清晰地写出来时，你会发现自己对它的理解远比想象中深刻。

通过写作，我可以：

- 系统化整理知识
- 加深对技术的理解
- 与社区分享和交流
- 留下成长的印记
